# Greenden

Greenden is a student front-end project for discovering houseplants, flowers, and thoughtful gifts. It features a calm forest-green and mint design, responsive layouts, and locally stored images.

## Pages

- **Home** (`index.html`) — Introduction, collection highlights, and plant-care information.
- **Products** (`products.html`) — 12 houseplants and 8 flowers or gifts.
- **Contact** (`contact.html`) — Contact form and help topics.

## Built with

- HTML5
- Tailwind CSS 2.2.19 via CDN
- Local images stored in `images/`

## Run locally

Open `index.html` in a browser, or open the project folder in VS Code and use the Live Server extension. No build step is required.

## Note

The contact form is a static demo and does not send or store submissions. Photo sources are listed in `images/PHOTO-CREDITS.txt`.
